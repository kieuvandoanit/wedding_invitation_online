# Website Thiệp Cưới - Kiều Đoàn & Phạm Giàu

Website thiệp mời cưới dạng single-page, có animation cuộn trang và nhạc nền tự động phát.

## 📁 Cấu trúc dự án

```
wedding/
├── index.html          # Trang chính
├── style.css           # Stylesheet: phần bìa, giới thiệu, hai gia đình
├── style2.css          # Stylesheet: thư mời, xác nhận, album, lời cảm ơn
├── js.js                # Hiệu ứng animation khi cuộn trang
├── source/              # Thư mục chứa assets
│   ├── doc/             # Ảnh nền, ảnh thiệp, ảnh album
│   ├── favicon.png
│   ├── music.mp3        # Nhạc nền
│   ├── pin_map.svg
│   ├── thank.svg
│   └── volume.svg
└── README.md            # File này
```

## ✨ Tính năng

- Trang bìa với ảnh nền, ngày giờ, địa điểm tổ chức và nút liên kết Google Maps
- Giới thiệu hai gia đình (Nhà Trai / Nhà Gái)
- Giới thiệu Chú Rể & Cô Dâu
- Thư mời
- Khối xác nhận thông tin Lễ Tân Hôn
- Album ảnh cưới với hiệu ứng cuộn
- Nhạc nền tự động phát
- Responsive cho di động

## 🎨 Công nghệ sử dụng

- HTML5, CSS3 (animation, transition), Vanilla JavaScript
- Google Fonts: Alex Brush, Montserrat, Noto Serif Display
